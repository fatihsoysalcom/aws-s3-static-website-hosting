# AWS S3 Static Website Hosting

This example demonstrates deploying a simple static website to AWS S3, showcasing cloud-based file storage and serving. It uses the AWS CLI to create a bucket, upload files, and configure public access.

## Language

`bash`

## How to Run

1. Ensure you have AWS CLI installed and configured with credentials.
2. Run the script: bash deploy_s3_website.sh
3. Access the provided website URL in your browser.
